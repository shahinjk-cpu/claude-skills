## Auto-setup for all AI tools (Windows)

To link all 522+ skills into all installed AI tools automatically:

```powershell
powershell -ExecutionPolicy Bypass -File setup-all-ai-tools.ps1
```

## Restore on Linux / macOS (Claude only)

```bash
git clone https://github.com/shahinjk-cpu/claude-skills.git
cd claude-skills
bash install.sh
```
