# claude-skills

Backup of Shahin's Claude Code skills (~159 skills).

## Restore on new machine

```bash
git clone https://github.com/shahinkarimov/claude-skills.git
cd claude-skills
bash install.sh
```

## Install gstack separately

gstack is a git repo — install it directly:

```bash
git clone https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup
```

## Skills count

159 skills (excludes `gstack` and `gstack.bak` which are separate git repos).
