## 🚀 1-Click Universal Bootstrap (İstənilən Kompüterdə 1-Kliklə Quraşdırma)

Bu repozitoriyanı istənilən yeni kompüterə (Windows, macOS və ya Linux) çəkdikdə, tək bir əmrlə bütün **5,101+ skill** və **Universal Auto-Router** avtomatik quraşdırılır:

### Windows (Masaüstü və ya Terminal)
```cmd
git clone https://github.com/shahinkarimov/claude-skills.git
cd claude-skills
setup.bat
```
*(və ya `setup.ps1` PowerShell vasitəsilə)*

### Linux / macOS
```bash
git clone https://github.com/shahinkarimov/claude-skills.git
cd claude-skills
chmod +x setup.sh && ./setup.sh
```

**Quraşdırıcı nə edir?**
1. Bütün 5,101 skill-i hədəf AI agent qovluqlarına (`~/.gemini/config/skills`, `~/.claude/skills`, `~/.cursor/skills`, `~/.codex/skills`, `~/.agents/skills`) sinxronlaşdırır.
2. `skills_manifest.json` və `skills_index.md` indekslərini yerləşdirir.
3. `AGENTS.md` və `CLAUDE.md` vasitəsilə 22 Core Məcburi Skill qaydalarını aktivləşdirir.
4. Universal Auto-Router-i işə salır.

## ⚡ Universal Auto-Router Necə İşləyir?

Repozitoriya daxilindəki [skill_router.py](file:///C:/Users/shahin.karimov/claude-skills/skill_router.py) və [skills_manifest.json](file:///C:/Users/shahin.karimov/claude-skills/skills_manifest.json) sayəsində agent istənilən tapşırığa uyğun ən yaxşı skill-ləri dərhal tapır:

```bash
# İstənilən tapşırıq üçün ən yaxşı skill-ləri tap:
python skill_router.py "react responsive dashboard animation"
```

Nəticə olaraq router ən uyğun skill-lərin siyahısını və `SKILL.md` ünvanlarını çıxarır, agent həmin təlimatları oxuyaraq işi ən yüksək standartlarla icra edir.
