# Claude Make An Anime — Multi-Shot Anime Production Studio

Transforms short text stories or markdown scripts into complete, multi-shot anime sequences with consistent art direction, character sheets, and camera choreography.

## Production Pipeline
1. **Character Design Bible**: Generate front, side, and expression turnarounds with locked color tokens and costume specs.
2. **Shot-by-Shot Storyboard**: Define shot types (extreme close-up, panning tracking shot, Dutch angle) and action beats.
3. **Generation Prompts**: Produce exact Fal.ai / Kling / Midjourney prompts retaining negative prompts for anime style purity.
4. **Dialogue & Audio Mix**: Localized Japanese/English voice generation prompts and BGM cue timing.
