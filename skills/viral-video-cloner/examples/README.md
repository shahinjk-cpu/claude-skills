## Reading a plan

```jsonc
{
  "mode": "object-swap",          // or "motion-transfer"
  "start": 0, "end": 8,           // the part of the source to recreate, in seconds
  "resolution": "720p",
  "plan": {
    "targets": [{                 // object swap: what to replace, by role, and with what
      "target": "the tumbler she holds up beside her face",
      "images": [1],              // reference image numbers, in the order listed in the example
      "who": "a sage-green enamel moka pot with a wooden handle"
    }],
    "constraints": ["No text, captions, labels or logos anywhere"]
  }
}
```

Motion-transfer plans use `scene`, `shots`, `subjects` and optionally `place` instead of `targets`.
Newer ChatCut versions also let an object-swap plan add `scene`, `stays` and `shots`, a shot-by-shot
guide for the edit. The object-swap plans here were submitted before that, so they leave them out.
Your agent reads the current format from the tool. See [docs/how-it-works.md](../docs/how-it-works.md).
