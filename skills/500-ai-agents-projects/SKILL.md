# 500+ AI Agent Projects & Architecture Blueprints

A structured reference guide and blueprint selector for 500+ open-source AI agent implementations across industries: autonomous coding, customer support, web scraping, financial research, and multi-agent coordination.

## Agent Architecture Taxonomy
- **ReAct (Reason + Act)**: Interleaved reasoning and tool calls for deterministic linear tasks.
- **Plan-and-Solve**: Planner generates full task DAG, executor carries out sub-tasks.
- **Multi-Agent Society**: Specialized roles communicating via pub/sub or round-robin boards.
- **Self-Reflective Loop (Reflexion)**: Agent critiques its own failed steps and writes dynamic memory lessons.

## Directory Reference
Includes blueprints for AutoGPT, MetaGPT, CrewAI, LangGraph, OpenHands, Smolagents, and Hermes/OpenClaw.
