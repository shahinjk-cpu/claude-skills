# Applications tracker

Status: `prepared` → `submitted` → `screening` → `interview` → `offer` / `rejected` / `withdrawn` / `ghosted`.
"Last update" = last time the status was confirmed. Rows ≥ 5 days old get a follow-up question.
The scan filter reads the Company column (row format below) to flag jobs already applied to.
