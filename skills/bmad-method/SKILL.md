# BMAD Method — Breakthrough Agile AI Development

An AI-native software development methodology orchestrating four specialized collaborative roles: Product Manager, Software Architect, Core Developer, and QA Engineer.

## The 4 Roles
- **Product Manager (PM)**: Clarifies user stories, acceptance criteria, and edge cases.
- **System Architect**: Designs data schemas, API contracts, and validates non-functional requirements.
- **Core Developer**: Implements clean, typed, modular code adhering to the architecture spec.
- **QA Engineer**: Writes unit, integration, and fuzz tests to verify all acceptance criteria before sign-off.
