# Pangolin — Identity-Aware Secure Reverse Proxy & Tunnels

A modern alternative to Cloudflare Tunnels and ngrok. Exposes local developer services, AI dashboards, and home servers to public domains with built-in SSO authentication.

## Core Features
- End-to-end encrypted wireguard/quic tunnels.
- OIDC / Google / GitHub OAuth authentication gates.
- Automatic Let's Encrypt TLS certificate provisioning.
