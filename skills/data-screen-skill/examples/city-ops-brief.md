# 大屏需求 brief（示例）

> 输入：「我们区里要做个城市运行指挥大屏，领导看，1920×1080，深蓝科技风，
> 要有事件、办结、网格员、地图、趋势、告警，数据先用示例，后面接我们自己的 REST 接口。」

## 1. 一句话

为区领导在指挥中心汇报场景，展示全区城市运行事件的总量、处置效率与空间分布，
让其在 3 分钟内看懂「今天发生了什么、处理得怎么样、哪里压力最大」。

## 2. 场景与规格

| 项 | 值 |
|---|---|
| 用途 | 领导汇报 + 日常值守 |
| 分辨率 | 1920×1080（16:9） |
| 观看距离 | 3–5m |
| 浏览器 | Chrome / Edge 90+，可离线 |
| 交付 | 静态目录 + `serve.mjs` 预览 + 截图 |

## 3. 信息架构

| 优先级 | 区域 | 内容 | 图表 | 数据路径 |
|---|---|---|---|---|
| P0 | 顶栏 | 标题、数据状态、日期时间、全屏 | — | `meta` |
| P0 | KPI 行 | 事件总量 / 已办结 / 现场处置 / 在岗网格员 / 满意度 / 未闭环预警 | 数字滚动 | `kpis.*` |
| P0 | 中心 | 全域事件态势（省份着色 + 涟漪 + 飞线） | map + effectScatter + lines | `geo` |

| P1 | 中下左 | 按时办结率 | 仪表盘 | `series.gauge` |

## 4. 数据

- 当前：`data/mock.json`（虚构数据，页面标「示例数据」）
- 接口：REST `GET /api/screen/city-ops`，30s 轮询
- 契约：`knowledge/data/data-contract.md` v1.0
- 映射：若后端字段不同，写 `window.DashboardTransforms.cityOps`
- 容错：8s 超时、3 次重试、失败保留上一帧、状态灯变「数据延迟」

## 5. 视觉

- 模板：`general-blue`（A1 三栏中心地图）
- 主题：T1 深蓝科技；主色 `#35d6ff`；强调 `#ffc93c`
- 字体：系统中文 + Rajdhani 数字
- 布局：420px / 1fr / 420px，24px 安全边距，14px 间距
- 禁止：紫色渐变、圆角玻璃卡、emoji、12 色同屏

## 6. 假设（待确认）

1. 假设为区级、16:9、中文。
2. 假设指标口径为「今日 00:00 至今」。
3. 假设「事件」包含 12345、网格、城管三类来源（可在接入时拆分）。
4. 演示数据为虚构，不代表真实业务。
