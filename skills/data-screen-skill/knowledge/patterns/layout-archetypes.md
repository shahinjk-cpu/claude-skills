# 布局原型 A1–A6

> 所有尺寸以 1920×1080 设计稿为准，再整体等比缩放。
> 大屏不是响应式网页：**先保证一个基准分辨率完美，再谈其他比例**。

## 0. 基准参数

| 项 | 值 | 说明 |
|---|---|---|
| 设计稿 | 1920×1080 | 16:9，LED/投影最常见 |
| 安全边距 | 24px | 拼接屏边缘会被边框吃掉 10–20px |
| 栅格间距 | 14px（8 的倍数） | 12/14/16 都可，全屏统一 |
| 顶栏 | 88px | 标题 + 状态 + 时钟 |
| KPI 行 | 120–140px | 4–6 个 |
| 底栏 | 40–48px | 播报/状态，可选 |
| 主内容高 | 1080 − 24×2 − 88 − 132 − 44 − 14×3 ≈ 730px | 三行结构 |
| 正文字号 | ≥ 14px | 投屏后 3 米可读；KPI 数字 40–56px |
| 面板标题 | 16–18px | 不要超过 20px，否则抢主视觉 |

## 0.1 三种缩放方案（必选其一）

**S1 · transform: scale（推荐）**

```css
.stage { width:1920px; height:1080px; transform: scale(var(--s)); transform-origin:center center; }
```
```js
const s = Math.min(innerWidth / 1920, innerHeight / 1080);
document.documentElement.style.setProperty("--s", s);
```
优点：像素级还原设计稿，图表/文字比例完全一致。缺点：极端宽高比会留黑边（用背景色填充即可）。

**S2 · rem（原模板常用）**

```js
document.documentElement.style.fontSize = innerWidth / 20 + "px"; // 1rem = 96px @1920
```
优点：文字可随宽度连续缩放。缺点：只随宽度、不随高度，16:10 / 竖屏会溢出；`calc()` 与 1px 边框混用易出小数模糊。

**S3 · vw/vh + clamp**

适合内容型大屏（可滚动、非固定画布），不适合 LED 拼接。用 `clamp(14px, 1.1vw, 22px)` 控制字号。

> 结论：**固定画布用 S1；需要嵌入既有 rem 项目才用 S2；网页化看板用 S3。**

## 1. A1 · 三栏 + 中心地图（最通用）

```
┌──────────────────────────────────────────────────────────┐
│ 标题                              状态 · 天气 · 时钟      │  88
├──────────────┬──────────────────────────┬────────────────┤
│ KPI 数字翻牌  │      中心地图（60% 高）    │  图表面板      │
│ 图表 1        │  涟漪点 / 飞线 / 省份着色  │  图表 4        │
│ 图表 2        ├──────────────────────────┤  图表 5        │
│ 环形占比 ×3   │  底部指标条 / 排行榜       │  图表 6        │
└──────────────┴──────────────────────────┴────────────────┘
   30%                    40%                    30%
```

```css
.grid { display:grid; grid-template-columns: 30% 40% 30%; }
/* 或精确版：grid-template-columns: 560px 1fr 560px; gap:14px; */
```

**内容预算**：左右各 3 个面板（1 大 2 小），中心 1 地图 + 1 条带。
**代表**：general-blue、retail、tourism、ecommerce-gov。
**适用**：领导汇报、区域总览、行业门户。**优点**：对称、稳、改造成本最低。

**常见错误**：中心地图只放一张静态图，没有数据层次 → 至少要有「区域着色 + 点位 + 飞线」中的两种。

## 2. A2 · 三栏高密度（指挥中心）

```
┌──────────────────────────────────────────────────────────┐
│ 电路感标题条 / 双行大标题                                  │
├──────────────┬──────────────────────────┬────────────────┤
│ 柱线复合      │  4 枚 KPI 小卡（横排）     │  雷达图        │
│ 多线趋势      │                          │  排行榜        │
│ 排行榜        │      中心飞线地图          │  人形图标行    │
│ KPI 列表      ├──────────────────────────┤  环形进度 ×3   │
│              │  底部实时收费 / 事件流      │                │
└──────────────┴──────────────────────────┴────────────────┘
   24%                    52%                    24%
```

```css
.grid { display:grid; grid-template-columns: 460px 1fr 460px; gap:14px; }
```
**内容预算**：8–14 个面板；每个面板只表达 1 个结论。
**代表**：highway、logistics、medical。
**适用**：交通、物流、应急等需要「同时盯很多指标」的场景。
**硬约束**：面板数 > 10 时，字号不得低于 12px，且必须用「标题 + 主数字 + 迷你图」的三层结构，否则投屏不可读。

## 3. A3 · 全屏 GIS + 浮层

```
┌──────────────────────────────────────────────────────────┐
│ 顶部标题条（半透明，压在底图上）                            │
│┌─────────┐                                    ┌─────────┐│
││ 总指标   │                                    │ 告警列表 ││
││ 图例     │        全屏地图 / 卫星底图            │ 排行     ││
│└─────────┘                                    └─────────┘│
│              底部时间轴 / 图例 / 播报                       │
└──────────────────────────────────────────────────────────┘
```

```css
.map-layer { position:absolute; inset:0; z-index:0; }
.hud { position:absolute; inset:24px; z-index:2; pointer-events:none; }
.hud > * { pointer-events:auto; }
```
**代表**：vehicle、ops-map、land-3d、traffic-video。
**适用**：空间信息是主角（点位、轨迹、视频、地块）。
**注意**：浮层卡片必须给地图留出 40% 以上可视面积；否则不如用 A1。
**性能**：全屏地图 + 1000+ 点位时用 `canvas` 渲染、`large:true`、关闭 `animation`。

## 4. A4 · 网格卡片（最容易规模化）

```
┌──────────────────────────────────────────────────────────┐
│ 标题                                            时间      │
├────────┬────────┬────────┬────────┬────────┬─────────────┤
│ KPI 1  │ KPI 2  │ KPI 3  │ KPI 4  │ KPI 5  │ KPI 6       │
├────────┴────────┼────────┴────────┼────────┴─────────────┤
│ 趋势（2×1）      │ 占比（1×1）      │ 排行（1×2）          │
├─────────────────┼─────────────────┤                     │
│ 表格（2×1）      │ 地图（1×1）      │                     │
└─────────────────┴─────────────────┴─────────────────────┘
```

```css
.grid { display:grid; grid-template-columns: repeat(12, 1fr); grid-auto-rows: minmax(0, 1fr); gap:14px; }
.span-4 { grid-column: span 4; } .span-6 { grid-column: span 6; } .span-8 { grid-column: span 8; }
```
**代表**：tax、device、store、stats、construction、finance-risk、operation。
**适用**：经营分析、统计报表、设备监控。
**关键**：KPI 卡与图表卡要有明确的视觉层级差异（KPI 用 40px+ 数字，图表卡弱化标题），否则整屏像 Excel。

## 5. A5 · 低密度叙事（汇报型）

```
┌──────────────────────────────────────────────────────────┐
│                    超大标题（居中）                        │
│┌──────────┐                              ┌──────────────┐│
││ 小面板    │        中心主视觉             │ 小面板        ││
││          │   关系网络 / 拓扑 / 3D 模型     │              ││
│└──────────┘                              └──────────────┘│
│              一句话结论 / 关键数字                          │
└──────────────────────────────────────────────────────────┘
```

**代表**：gov-neon。
**适用**：领导参观、展厅、系统架构介绍。信息量小，但**主视觉必须精致**。
**风险**：中心图如果只是装饰，整屏会空。必须让中心图承载真实关系数据（节点/边/流量）。

## 6. A6 · 硬边终端风

```
┌──────────────────────────────────────────────────────────┐
│ 细线框标题（等宽字体 / 全大写英文）                         │
├────────────┬──────────────────────────┬──────────────────┤
│ 仪表盘 ×2   │       中心地图            │ 玫瑰图 / 数值块   │
│ 柱线图      │                          │ 仪表盘 ×4        │
└────────────┴──────────────────────────┴──────────────────┘
```

**特征**：无圆角、无渐变、1px 细线、荧光单色、等宽数字、`UPPERCASE` 英文标签。
**代表**：weather、ops-ring。
**适用**：气象、工业、实验室、想与「蓝色科技风」拉开差距的展厅。
**注意**：荧光色只做线条和数字，不要大面积填充；投影仪会偏色，交付前实测。

## 7. 特殊比例

| 场景 | 尺寸 | 策略 |
|---|---|---|
| 4K LED | 3840×2160 | 仍按 1920×1080 设计，scale=2；字体/线宽自动放大，无需改代码 |
| 超宽拼接（1×3） | 5760×1080 | 按 1920 一个「屏块」设计，重复三块或做 3 个逻辑区；不要把一个 16:9 拉宽 |
| 竖屏 | 1080×1920 | 单列：标题 → KPI 2×3 → 主图 → 2 个图表 → 滚动列表；不要硬套三栏 |
| 网页看板 | 自适应 | 12 栅格 + `clamp()` + 允许纵向滚动；图表用 `ResizeObserver` |

## 8. 布局自检

- [ ] 1080p 下无横向/纵向滚动条
- [ ] 安全边距内没有关键信息
- [ ] 每个面板有明确的「主数字/主趋势」
- [ ] 视觉重心明确（通常是中心地图或中心 KPI）
- [ ] 左右栏宽度一致（A1/A2），或按 12 栅格对齐（A4）
- [ ] 面板间距全屏一致（不要 13/14/15 混用）
- [ ] 缩放到 1366×768 仍可读（最小字号折算 ≥ 10px）
- [ ] 竖屏/超宽有单独断点，而不是硬拉伸
