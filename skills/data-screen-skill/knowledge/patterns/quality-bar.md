# 交付质量线（40 项）

> 三级：**E** = 阻塞交付，**W** = 应有，**N** = 加分。
> 每次改完先跑 `node scripts/qa.mjs <dir>`，再人工过一遍下面清单。

## A. 信息架构（8）

- [ ] **E** 一屏一个主题，标题能说清「谁、看什么、什么时间」
- [ ] **E** KPI ≤ 6 个，且有单位
- [ ] **E** 每个面板能用一个短标题概括，不出现「模块标题样式」
- [ ] **W** 有明确的视觉重心（地图/主 KPI/主趋势）
- [ ] **W** 模块有主次：必须看的 ≤ 3 个，其余为辅助
- [ ] **W** 图表类型与数据关系匹配（见 `chart-recipes.md` 选型表）
- [ ] **N** 有一句「结论式」文案（如「办结率较昨日 +3.2pt」），而非只有数字
- [ ] **N** 有数据口径说明（时间范围/单位/来源）

## B. 视觉（10）

- [ ] **E** 1920×1080 下无滚动条、无裁切、无内容溢出
- [ ] **E** 关键内容在 24px 安全区内
- [ ] **E** 正文 ≥ 14px，KPI ≥ 40px，图表标签 ≥ 11px
- [ ] **E** 无未替换占位文案/示例图片/英文 lorem
- [ ] **W** 全屏颜色 ≤ 6 种（不含中性色）
- [ ] **W** 一个面板最多 1 主色 + 1 语义色
- [ ] **W** 标题/数字/正文层级在灰度截图下仍可分
- [ ] **W** 面板样式统一（边框/圆角/标题条只有一种）
- [ ] **N** 有背景纹理/光效，但不干扰数据
- [ ] **N** 3 米外可读（投屏实测）

## C. 数据（8）

- [ ] **E** 演示数据全部标注「示例数据」，不冒充真实业务
- [ ] **E** 数字格式统一（千分位、小数位、单位、亿元/万元）
- [ ] **E** 无 `NaN` / `undefined` / `null` 直接渲染
- [ ] **W** 空数据有「暂无数据」占位
- [ ] **W** 接口失败保留上一帧 + 状态提示（不白屏）
- [ ] **W** 时间/时区/日期格式统一（建议 `YYYY-MM-DD HH:mm`）
- [ ] **W** 负数、0、极大值都有合理展示
- [ ] **N** 同比/环比有基期说明

## D. 技术（9）

- [ ] **E** 无 JS 报错（控制台）
- [ ] **E** 所有本地资源路径正确（移动目录后仍可运行）
- [ ] **E** 有 viewport meta + 缩放方案
- [ ] **W** 图表在 resize / 字体加载后重新布局
- [ ] **W** 定时器在页面隐藏时暂停，组件销毁时清理
- [ ] **W** 图表实例复用（`getInstanceByDom`），不重复 `init`
- [ ] **W** 离线模式无外网依赖（字体/地图/ECharts 全本地）
- [ ] **W** 无明显内存增长（连续运行 30 分钟）
- [ ] **N** 支持 `prefers-reduced-motion`

## E. 交付（5）

- [ ] **E** 有启动方式说明（本地预览 / Nginx / 静态托管）
- [ ] **E** 有数据接口说明（地址、字段、频率、鉴权）
- [ ] **W** 有截图（1920×1080）与目录结构说明
- [ ] **W** 标注浏览器要求（建议 Chrome/Edge 90+）
- [ ] **N** 提供主题切换/换肤说明

## 常见「一票否决」

1. 把 `.html` 从原目录单独拷出来 → 相对路径全断。
2. ECharts 2 的 `option` 直接喂给 ECharts 5 → 图表空白。
3. 地图 GeoJSON 省份名与数据名不一致 → 整块不着色。
4. 图表容器高度为 0（父级 flex 未给 `min-height:0`）→ 只有标题没有图。
5. 用 `setInterval` 每 2s 重建整个 DOM → 滚动位置丢失、内存上涨。
6. 多个 ECharts 版本同时加载 → 后加载的覆盖全局 `echarts`。
7. 演示数据写成真实企业名/真实人名 → 合规风险。
8. 只做 hover 提示，没有常驻数值标签 → 大屏无法读数。

## 评分建议

| 得分 | 判断 |
|---|---|
| E 全过 + W ≥ 80% | 可交付 |
| E 全过 + W < 80% | 可演示，需列整改清单 |
| 有 E 未过 | 不交付 |

## 自检命令

```bash
node scripts/qa.mjs screens/my-screen          # 静态检查
node scripts/serve.mjs screens/my-screen       # 本地预览
# 浏览器 1920×1080 截图，检查：
#   1) 控制台无报错  2) 无滚动条  3) 断网后状态灯变红但页面不白
```
