# Motion Skills: Master Motion & Animation Suite

The **Motion Skills** ecosystem is a collection of 30+ agent-native skills covering motion design craft, video production, web animations, kinetic typography, and AI video workflows.

## Categorized Skill Matrix

### 1. Motion Design & Craft
- `animation-principles`: The 12 Disney animation principles (squash/stretch, anticipation, staging, follow-through) in CSS & code.
- `motion-art-direction`: Visual rhythm, easing curves, brand motion identity, and scene choreography.
- `shot-composition`: Cinematic framing, rule of thirds, safe zones (16:9, 9:16), focal hierarchy.
- `color-motion`: Color palettes in motion, harmonious transitions, gradients, and chroma styling.

### 2. Video Production & Engines
- `remotion-video`: Programmatic React/TypeScript video rendering with Remotion (compositions, sequences, springs).
- `after-effects`: Adobe After Effects scripting (ExtendScript, JSX), expressions, and project automation.
- `beat-sync-editing`: Music-driven cutting, transient markers, BPM synchronization, and rhythm-locked pacing.
- `logo-animation`: Logo reveals, stroke draw-on, SVG morphing, and brand stingers.
- `motion-background`: Seamless looping backgrounds, mesh gradients, particle fields, and ambient textures.

### 3. Web & UI Animation
- `60fps-animation`: High-performance CSS transforms, `will-change`, composite layers, and jank prevention.
- `gsap-web`: GreenSock Animation Platform (ScrollTrigger, Flip, SplitText, timelines).
- `svg-animation`: Vector stroke dashes, path morphing, SMIL/CSS vector motion.
- `lottie-animation`: Web & mobile Lottie/Bodymovin integrations and event triggers.
- `micro-interaction`: Hover states, button ripples, switch bounces, and tactical UI feedback.
- `page-transition-animation`: Smooth route changes, shared element transitions, layout animations.
- `accessible-animation`: Respecting `prefers-reduced-motion` and WCAG motion compliance.
- `glassmorphism`: Frosted glass UI cards, backdrop-filter blurs, and layered specular highlights.
- `ascii-animation`: Terminal & retro ASCII text animations and matrix effects.

### 4. Typography & Social Video
- `kinetic-typography`: Beat-synced animated titles, split-text staggered reveals, variable font weighting.
- `short-form-video`: Vertical 9:16 video architecture for TikTok, Instagram Reels, and YouTube Shorts.
- `caption-animation`: Word-by-word karaoke style captions with bounce highlights.
- `lower-thirds`: Broadcast-quality transparent name tags, handles, and lower third overlays.
- `countdown-video`: Dynamic timers, countdown clocks, and progress circles.

### 5. Data & Explainers
- `chart-animation`: Animated bar charts, line plots, donut meters, and number counters.
- `animated-infographic`: Multi-step visual data stories with staggered reveals.
- `diagram-animation`: Flowcharts, node graphs, and architectural sequence reveals.
- `explainer-video`: Structured 60-90s educational and SaaS product explainer films.
- `isometric-animation`: 2.5D isometric scenes, faux 3D rotations, and building block layouts.
- `whiteboard-animation`: Hand-drawn write-on vectors and chalkboard explainer effects.
- `wrapped-video`: Spotify Wrapped-style personalized stat summary presentations.
- `presentation-video`: Keynote-quality animated pitch decks and slide videos.

### 6. AI Video & Motion Cloning
- `motionclone`: Training-free reference motion cloning for Text-to-Video and Image-to-Video (ICLR 2025).
- `stageshow`: Benji Taylor's faux UI, animated cursor walkthroughs, and bento demo clips.
- `rea-video`: Reactive video generation and montage flows.
- `animated-shorts`: Automated short-form animation scripting and storyboard pipelines.

## How to Select the Right Skill

- **For React/Code-based Video**: Use `remotion-video`.
- **For High-End Web Animation**: Use `gsap-web` + `60fps-animation`.
- **For Kinetic Titles or Social Clips**: Use `kinetic-typography` + `short-form-video`.
- **For AI Motion Transfer**: Use `motionclone`.
- **For SaaS Product Walkthroughs**: Use `stageshow` + `explainer-video`.
