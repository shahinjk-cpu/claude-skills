# YouTube Automation Agent Workflow

An end-to-end autonomous agent workflow for producing, optimizing, and scheduling YouTube video content.

## Production Pipeline
1. **Trend & SEO Research**: Discover high-search, low-competition keywords in your niche.
2. **Hook-First Scriptwriting**:
   - First 5 seconds: Visual hook + problem statement.
   - 0:05–0:30: Promise of payoff.
   - Body: 3 structured retention-focused beats.
   - Outro: 10-second CTA with end-screen card cue.
3. **Voiceover Generation**: Generate natural pacing with ElevenLabs or Sherpa-ONNX.
4. **B-Roll & Visual Assembly**: Combine screen recordings or Remotion animations.
5. **Title & Thumbnail A/B Testing**: Generate 3 high-CTR title candidates and thumbnail briefs.
