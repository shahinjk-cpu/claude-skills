# Nota — Prose-First Local Documentation

A distraction-free writing and linked-knowledge standard optimized for technical authors, engineering logs, and interconnected architectural notes.

## Conventions
- Wikilink syntax `[[Concept]]` for internal conceptual cross-references.
- Standard GitHub Flavored Markdown with KaTeX math and mermaid flowcharts.
- Frontmatter containing `title`, `tags`, `created_at`, `status`.
