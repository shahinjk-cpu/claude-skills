# Univer — Open-Source Enterprise Canvas Office Suite

Integrates Univer, an ultra-fast canvas-rendered spreadsheet, document, and slide engine built for modern web applications.

## Capabilities
- High-performance canvas rendering handling 1,000,000+ spreadsheet cells smoothly.
- Full Excel formula compatibility (VLOOKUP, XLOOKUP, INDEX/MATCH, Array formulas).
- Headless Node.js workbook manipulation and calculation engine.
