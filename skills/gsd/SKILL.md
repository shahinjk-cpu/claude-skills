# GSD (Get Shit Done) — Spec-Driven Agent Execution

A high-velocity execution framework for AI coding agents that eliminates endless planning loops and context decay.

## The GSD Operating Protocol
1. **Spec First (SDD)**: Define explicit acceptance criteria before touching any code.
2. **Chunking**: Break initiatives into independent sub-tasks each executable in a single agent turn.
3. **No Apologies, Only Diff**: Never apologize or output conversational fluff; generate concrete, verified code diffs and test outputs.
4. **Context Hygiene**: Reset or compact context after major milestones to prevent reasoning degradation.
