# Drafting a cover letter for a good match

A draft for the user to edit and send, never something sent for them.

## Rules
- **Only facts from the CV and profile.** Never invent experience, numbers, tools or motivations. If a strong letter needs a fact you don't have, write `[ask: how many users used X?]` in the draft and list these gaps in your reply.
- **Write in the language of the ad**, unless the profile says otherwise.
- **Use the ad's exact key terms** where they are true of the user. It helps ATS keyword matching and shows the user read the ad.
- **One real, specific fact about the company,** from the ad or the company's own site: a product, a project, a value with substance. Not "leader in its field". If you can't find one, leave `[ask: why this company?]`.
- **Address it properly:** the contact person's name if the ad gives one, otherwise "Dear Hiring Team" / "Madame, Monsieur" / "Sehr geehrte Damen und Herren". Add the employer's address when the ad or company site gives it.
- **No invented feelings or habits either:** "I've always dreamed of…", "I use X every day" or "this is exactly what I want to build" are claims too. Keep only motivations the user gave, or leave an `[ask: …]`.
- **Grammatical gender:** use the profile setting. If it isn't set, use phrasing with no gendered agreement: write "Ce serait un plaisir d'en parler", not "Je serais heureux/heureuse d'en parler".
- **Keep it short:** body (without addresses and subject line) 150–250 words, 3–4 paragraphs, one page.
- **If the user has a letter they like** (the path is in the profile), match its voice, structure and closing.

## Structure
1. **Opening (2 sentences):** the role, plus the one specific thing about this company that makes it a fit. No "I am writing to express my interest".
2. **Proof (2 short paragraphs):** the two achievements from the CV that best match the ad's must-haves, each with its result.
3. **Practical details (1–2 sentences):** availability, workload, location or relocation, languages if the ad asks for them.
4. **Close (1 sentence):** an invitation to talk, then a single sign-off line.

## Avoid
Clichés and AI tells: "passionate", "results-driven", "dynamic", "delve", "fort de", "force de proposition", "I am confident that". If the `cv-check` skill is installed, run it on the draft.
