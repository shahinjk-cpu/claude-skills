# Phosphene — Generative Visuals & Shader Playground

Builds interactive, audio-reactive visual synthesizers and GPU-accelerated canvas animations using WebGL and GLSL shaders.

## Design Patterns
- Ray marching 3D fractals and SDF geometries.
- FFT audio frequency mapping to visual displacement and color palettes.
- Frame-rate optimized buffer swapping for continuous 60fps rendering.
