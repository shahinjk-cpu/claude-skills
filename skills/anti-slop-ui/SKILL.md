# Anti-Slop UI & Web Craft Manifesto

AI code generators often suffer from 'AI Slop': identical purple gradients, floating cards with glowing borders, giant meaningless icons, and zero information density. This skill enforces restraint and editorial craftsmanship.

## Prohibited Slop Patterns
- 🚫 Purple-to-pink linear gradients (`from-purple-600 to-pink-500`)
- 🚫 Low-contrast light grey text on white cards
- 🚫 Meaningless 3-card feature grids with giant checkmark icons
- 🚫 Pointless hero illustrations of generic 3D blobs

## Approved Craft Principles
- ✅ Typography-first hierarchy: Strict type scales, tight tracking (`tracking-tight`), crisp mono accents.
- ✅ Dense, functional data layouts: Tabular data alignment, clear 1px borders (`border-zinc-800`), muted subtle backgrounds (`bg-zinc-950`).
- ✅ Purposeful color: Restrained accents (single cyan, amber, or emerald indicator used only for real state).
