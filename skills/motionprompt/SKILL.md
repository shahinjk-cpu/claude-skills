# MotionPrompt — AI UI & Motion Prompt Engineering

MotionPrompt is a systematic framework for generating precise, production-ready motion choreography prompts and CSS/Framer Motion code for AI coding agents.

## Core Motion Tokens
- **Spring Physics**: Stiffness, damping, and mass configurations for natural tactile response.
- **Micro-Interactions**: Hover, click, tap, and drag state feedback.
- **Stagger & Cascade**: Sequential element entrance choreography.

## Prompt Blueprint
```markdown
When designing UI motion:
1. Define Spring Physics: stiffness 400, damping 30, mass 0.8.
2. Restraint: Max duration 250ms for micro-interactions, 400ms for full-page transitions.
3. Accessibility: Always honor `prefers-reduced-motion` with an instant opacity fade fallback.
```
