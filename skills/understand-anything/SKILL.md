# Understand Anything — First-Principles Conceptual Deconstruction

Deconstructs any foreign codebase, abstract mathematical proof, or complex distributed system into crystal-clear, intuitive mental models using the Feynman technique.

## Deconstruction Steps
1. **The Core Invariant**: What single fundamental problem does this system exist to solve?
2. **Physical Analogy**: Ground abstract software or math concepts in familiar physical objects.
3. **Failure State Analysis**: What breaks if this component is removed?
4. **Concrete Trace**: Walk through a single byte or token moving through the system from input to output.
