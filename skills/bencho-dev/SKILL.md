# Bencho.dev — Motion Primitives & Micro-Interactions

A curated collection of micro-interactions and interactive React UI components designed for high-polish frontend engineering.

## Component Patterns
- **Magnetic Buttons & Selects**: Physics-based cursor attraction and smooth spring return.
- **Segmented Sliders**: Layout-animated pill indicators with Framer Motion.
- **Morphing Toggles**: State transitions that physically morph geometric shapes.
- **Card Hover Glare**: 3D tilt with dynamic light glare calculated from mouse coordinates.

## Installation & Code Pattern
```bash
npm install framer-motion lucide-react clsx tailwind-merge
```
