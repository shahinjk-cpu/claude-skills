# OpenProject — Enterprise Project & Roadmap Manager

Automates issue tracking, milestone tracking, and team scheduling using the OpenProject REST API v3.

## Key API Endpoints
- Work Packages: `GET /api/v3/work_packages`
- Projects: `GET /api/v3/projects`
- Time Entries: `POST /api/v3/time_entries`
