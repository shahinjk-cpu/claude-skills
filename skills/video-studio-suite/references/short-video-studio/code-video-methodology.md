# 纯代码制片总纲与四大工艺规范（Code2Video Methodology）

> 适用场景：**零实拍、科普图解、数据故事、产品与 UI 动效演示、风格化 2D/3D 短片**，以及为实拍口播自动补足高信息密度动态讲解画面。

---

## 一、 核心原则：`frame(t) → image` 纯时间函数

纯代码视频的本质是确定性纯函数：第 `i` 帧画面完全由时间戳 `t = i / fps`（统一 `30fps`）唯一决定。

### 确定性四大工程铁律
1. **时间唯一输入**：所有位移、透明度、相机角度与形变均写成 `t` 的闭式表达式或分段缓动组合，严格经 `window.seek(t)` 驱动，严禁依赖 `Date.now()` 或 `requestAnimationFrame` 步长。
2. **固定随机数种子（PRNG Seed）**：粒子初速、背景噪点、纸张纤维必须在初始化阶段用固定种子生成并离屏缓存，帧内禁止调用非确定随机函数（根除闪烁）。
3. **物理与粒子预烘焙（Pre-bake）**：流体、弹跳、群落或粒子演化按固定步长（`1/60s` 或 `1/30s`）预计算快照，渲染 `t` 时仅插值读取。
4. **内嵌视频素材预抽序列帧（禁直播 `<video>` Seek）**：无头浏览器中反复 `video.currentTime` 极易黑帧或错帧。必须先用 `generate_code_broll.extract_clip_sequence()` 预抽 JPG 序列帧，预加载完成后在 `seek(t)` 按 `Math.floor(localT * fps)` 精确绘制。

## 二、 标准工作流：`Brief → SPEC + STRUCTURE → 渲染 → 像素取证`

1. **先立契约（`scripts/code_video_spec.py --init-spec` / `--validate-spec`）**：
   - **容器与画幅**：竖屏默认 `1080×1920` / 横屏 `1920×1080` / 方图 `1080×1080` / 封面 `1080×1440`，恒定 `30fps`（偶数宽高）。
   - **Verbatim 文案白名单与事实台账（Fact Ledger）**：未写入 `00_code_spec.json` 的价格、参数、日期与宣传词一律禁上屏；所有数字必须与台账出处一致。
   - **素材清单与禁改约束**：Logo 禁改色拉伸、产品实拍禁重绘失真、UI 截图局部动效需 50% 叠图校准。
   - **分幕时间表（`STRUCTURE.md`）**：按秒列出视觉演化、主事件与 2–3 个高危风险检查项。
2. **技术栈按内容匹配**：
   - 矢量卡片 / UI 演示 / 动态字体 / SVG 路径：HTML + Canvas 2D/SVG + `capture_html_video.mjs`；
   - 标准数据/流程/对比动态补镜：`generate_code_broll.py --backend auto`（优先无头 Chrome，缺浏览器回退 Pillow）；
   - 精密数学几何推演：Manim；立体空间穿行：Three.js（导出前按 `1/30s` 沿相机路径做球形 Raycast 防穿模）。
3. **耗时预算与分片编码**：先用 `capture_html_video.mjs --frames 3` 测最繁忙帧（目标 `≤ 300ms/帧`）；长片可用 `--start` / `--frames` 分片并发后 `ffmpeg -f concat -c copy` 无损拼合。

## 三、 四大专题工艺规范

### 工艺 1：图解科普与数据可视化（Explainer & Data）
- **一镜一核心命题 + 单一持久主例证**：全片围绕同一核心对象推演，用“视觉差变化”证明结论，不中途换喻体。
- **真实数值映射**：柱高、占比分段按真实数值线性计算，读取 `item["unit"]`，严禁默认强拼 `%`；同一对象在步骤切换间保持颜色与坐标插值连续（Object Identity）。
- **1080p 版面与字号硬底线**：核心主图占幅 `≥ 60%`（拒绝十几个小方块堆砌的伪仪表盘）；小标签 `≥ 28px`、正文 `≥ 36px`、主标题与结论数字 `≥ 64px`；竖屏主信息排在 `y ∈ [180, 1140]`，避让底部 `y ∈ [1180, 1468]` 字幕洁净带。
- **五种典型语域**：极简深色科技流（`#0B0F17`）、暖食手账流（`#FAF4E8`）、纸感手绘流（`#F4EFE6`）、强反差财经对比流、现代杂志留白流。

### 工艺 2：动效语法、品牌 Promo 与 UI 保真（Motion & Promo）
- **设计系统先行**：`1` 主背景 + `1` 表面卡底 + `1–2` 高对比强调色 + 最多 `2` 款经 `is_verified_commercial_font()` 认证的开源商用字体；全片围绕单一串联视觉母题（Motif）。
- **物理阻尼弹簧五段式质感**：微预备 → 果断发力 → 触达接触 → 轻微过冲回弹 → 可读停留。统一使用闭式 `damped_spring(t, t0, freq=2.2, zeta=0.58)`（纯时间函数、支持任意 Seek）；同组卡片交错 `2–5 帧`（`0.07–0.16s`）入场，任意时刻只保持一个视觉焦点。
- **停留时长公式边界（严禁混用）**：
  - **静音信息卡片 / 品牌 Promo（无旁白）**：中文停留 `hold_sec >= max(1.6, chars / 4.5 + 1.5)`，开篇/收尾标题卡 `≥ 2.0s`；英文 `letters / 15 + 1.5`。
  - **知识讲解动画无配音版**：见 [knowledge-animation-craft.md](knowledge-animation-craft.md)（按 `max(1.3, 字数/6.2)` + 标题加权）。
  - **口播/旁白主导成片**：严禁套静态卡片公式，直接跟随 `03_audio_events.json` 锁定人声起止时间。
- **先测后落位**：始终通过 `textbbox` / `getBoundingClientRect` 实测宽高，浅底抠图向内收 `1px` + 羽化 `1–2px` 核查深底无白边。

### 工艺 3：风格化渲染与无缝循环（Stylized & Generative）
- **风格四元组**：显式定义 ① 物质基底（宣纸/卡纸/拉丝铝/微颗粒）、② 笔触/轮廓生成方式、③ 有限角色色板、④ 反模式禁忌（如像素风禁抗锯齿模糊）。
- **稳定性铁律**：纹理/纸纹离屏一次绘成整片复用；主视觉先过纯黑剪影辨识度检验，文字对比度仍须过 WCAG `≥ 4.5:1`（单框 `≥ 3.8:1`）。
- **无缝循环数学构造（周期 `P` 秒，`N = round(P * fps)` 帧）**：只渲染帧 `0 .. N-1`；周期旋转用 `2π*k*t/P`；粒子寿命按 `((t - birth) % P + P) % P` 取模；2D 噪声场沿闭合圆 `(cx + r*cos(2πt/P), cy + r*sin(2πt/P))` 采样；验收时将末帧与第 0/1 帧紧接连看。

### 工艺 4：声音设计、听看分离与节拍同步（Sound & Beat Sync）
- **单一时间线（One Timeline）**：口播主导先锁 `03_audio_events.json` 再驱动画面；纯代码动画由时间轴事件表驱动 `synth_motion_sfx.py` 15 种拟音 + BGM，改剪辑必重算音轨。
- **语速预算与 `say`/`show` 分离**：中文自然语速 `220–260 字/分钟`（`3.7–4.3 字/秒`），`say` 给朗读纯字法、`show` 给精简上屏字，合规改写同步刷新两端；Edge TTS 落盘 48kHz WAV 后必用 `10ms RMS` 实测起音点纠偏 `WordBoundary` 约 `40–55ms` 的系统提前量。
- **拟音与播控底线**：优先真实物理材质 CC0 SFX（`vibe_sound/`）或 15 种无版权动效拟音，按 Peak Offset 提前起播令声峰砸中切点；切点吸附音乐节拍单次限 `80–150ms`；转折前可留 `≤ 0.45s` 真实底噪停顿制造反差。最终双声道 `48kHz AAC (192kbps)` 严格等长于视频（`≤ 1 帧`），**全仓统一响度目标 `-14.0 ± 1.5 LUFS`，生产目标真峰值 `≤ -1.5 dBTP`（黑盒硬门禁 `≤ -1.0 dBTP`）**。

## 四、 视觉取证三板斧与高频翻车速查

1. **Stills First + Cold Read（陌生人盲读法）**：先遮蔽代码意图盲读关键帧与 `review_pack/`，认不出主视觉或手机小图看不清字即判定未完成。
2. **Action Strips（动作连拍条）**：检查前 3 秒 `0.2s` 步长与切点前后 `0.15s` 步长连拍，排查瞬移、卡顿与字幕闪切。
3. **`VERIFY.md` 像素证据链**：逐项记录时间点与屏幕像素观感，拒绝空泛自证。

| 常见故障 | 根本原因 | 工程解法 |
| :--- | :--- | :--- |
| 成片播放加速/掉帧抖动 | 动画读 `Date.now()` 或依赖 `rAF` 步长 | 全改 `window.seek(t)` 闭式 `t` 函数 |
| 首帧空白或字体回退豆腐块 | 字体/图片未解码就截图 | 等 `await document.fonts.ready` 与 `img.decode()` 后置 `window.READY=true` |
| 背景噪点/笔触高频闪烁 | 每帧重新调随机扰动 | 初始化离屏一次性绘制并缓存贴图 |
| 内嵌视频黑屏或慢 3 帧 | 无头环境直播 `<video>` 反复 seek | `extract_clip_sequence` 预抽 JPG 序列按帧索引绘制 |
| 主体太小或被底字幕压住 | 凭感觉估坐标 | 主图 `≥ 60%` / 主体 `≥ 1/3`，实测 `textbbox` 且避开 `SUBTITLE_SAFE_ZONE` |
| 3D 镜头穿过物体内部 | 相机轨迹穿入模型碰撞体 | 每 `1/30s` 沿路径球形 Raycast 防穿模 |
