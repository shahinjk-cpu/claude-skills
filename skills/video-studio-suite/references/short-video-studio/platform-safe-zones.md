# 竖屏短视频平台 UI 遮挡区与居中字幕规范

标准成片画布尺寸：**1080 × 1920**（9:16 竖屏，30 fps 恒定帧率，BT.709）。

---

## 一、 平台 UI 遮挡危险区（兼容抖音 / 视频号 / 快手 / 小红书）

所有关键视觉元素（字幕、花字、贴纸、数据图核心文字、拍摄任务卡主体）**严禁**进入以下像素坐标区：

| 危险区域 | 坐标范围 (基于 1080×1920) | 平台遮挡原因 |
| :--- | :--- | :--- |
| **顶部状态/搜索栏区** | `Y: [0, 160)` | 状态栏、返回键、搜索栏、直播/同城角标 |
| **右侧互动按钮柱** | `X: (880, 1080], Y: [680, 1520]` | 头像关注、点赞、评论、收藏、转发、旋转唱片 |
| **底部信息与进度条区** | `Y: (1480, 1920]` | 账号名、视频文案、POI 定位/团购锚点、进度条、底部 Tab |
| **左侧极边缘** | `X: [0, 60)` | 手机曲面屏边缘裁切容错 |

### 安全区与对称居中字幕黄金坐标（`common.py` 单一事实源）
- **通用安全区 `SAFE_ZONE`**：`X: [60, 880]`，`Y: [160, 1480]`（用于花字、贴纸、标题封套与通用视觉要素）。
- **主字幕纵轴安全区 `SUBTITLE_SAFE_ZONE`**：`X: [80, 860]`，`Y: [1180, 1468]`（默认基线中心 `SUBTITLE_DEFAULT_Y_CENTER = 1310`，7 点自动避脸不越出 `1468`）。
- **主字幕绝对正中对称带 `SUBTITLE_SYMMETRIC_ZONE`**：`SUBTITLE_CENTER_X = 540`，左右对称约束在 **`X: [220, 860]`（安全对称净宽 `640px`，左右距边缘各留 `220px`）**，从根源消灭「偏左歪斜」或「偏右撞点赞栏」；MP4 渲染、剪映 FCPXML、HyperFrames 与白盒/黑盒质检（`qa_inspector.py` `#7` & `independent_verifier.py` `#13`）四端统一强锁。
- **首帧封面与 3:4 主页防裁切区**：9:16 封面中心 3:4 裁切窗为 `Y: [240, 1680]`，海报顶部引语下移至 `Y ≥ 262`，同步导出 `09_cover_3x4.jpg`、`09_ui_safe_preview.jpg` 并做 `180px` 缩略图真实像素对比度校验。

## 二、 28 套内置可商用字幕样式模板

配置定义于 `assets/subtitle_templates/templates.json`（含 **4 套基础轨道模板** + **24 套风格谱模板 `style_01` ~ `style_24`**，全库 100% 绑定免费可商用开源字体，零私有系统字体）：

1. **`store_bold_yellow` / `style_14`（默认门店原生爆款风 · 居中双字号暖黄高亮）**：
   - 门店实景高转化旗舰模板，默认用于**门店轨**。
   - **无底框** 62px 粗黑体白字 + 4px 粗黑描边；关键词放大 `1.133x`（70px）并高亮为暖金 `#FFE28A`，绝对正中于 `X=540, Y=1310`。
2. **`creator_clean_white`（基础极简白）与 `style_11`（默认博主风格谱）**：
   - `creator_clean_white` 为基础轨道模板：白字 + 深灰半透明圆角底框 + 天青蓝 `#4FC3F7` 关键词高亮；
   - `style_11` 为博主轨默认风格谱：干净通透圆角底框字幕 + 暖亮高亮色 + 角落圆形例证小窗。
3. **`contrast_red_punch`（强反差争议红黑）**：
   - 用于颠覆认知、内幕揭秘、对比警示等强冲击视频；深灰底框 `#18181BB8` + 强反差红 `#FF453A` 关键词高亮 + 5px 粗黑描边。
4. **`warm_persona_cream`（温情故事暖米色）**：
   - 用于创业经历、做事底线、真实故事类表达；暖米白 `#FFF8E7` + 柔和棕黑描边 + 暖橙高亮 `#FF8A65`。
5. **`style_01` ~ `style_24`**：完整映射 6 大视觉流派与 4 套高空镜形态（85%–100% 特写/实景/图解），详见 [STYLE_SPECTRUM_REPORT.md](../assets/style_spectrum/STYLE_SPECTRUM_REPORT.md)。

## 三、 包装预算上限与首帧信息密度规则

1. **包装预算上限（防止过度包装成“牛皮癣”）**：
   - 视觉包装元素（花字 + 贴纸 + 徽章）只放在 `03_audio_events.json` 标注的情绪点或核心信息点上，多区排布（顶部主标题 `Y=210` / 侧边情绪多区轮换 / 底部行动号召 `Y=920`）确保零堆叠。
   - 全片视觉包装总量上限：常规风格 `max_visual_elements = max(3, ceil(duration_sec / 3.5))`；高空镜风格（`style_21`–`style_24`）收紧为 `max(2, ceil(duration_sec / 5.5))`，留足画面呼吸感。
   - 任意连续 3 秒窗口内不超过 2 个贴纸/花字，单条文字卡片按字数停留不少于 `1.35s`。
   - 包装元素出现帧必须对齐对应的音效点或重音帧，允许误差 **`±1 帧`（≤ 33.3 ms）**。
2. **首帧画面信息密度**：
   - 第一帧（`t = 0.0s`）保证清晰主体 + 明确视觉焦点，严禁黑帧、纯色空屏或无重点的远景过渡帧。
