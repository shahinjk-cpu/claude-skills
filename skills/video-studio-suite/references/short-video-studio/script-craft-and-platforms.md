# 口播文案结构库、四轮审稿与多平台适配指南

> 核心原则：**真实性 > 流量技巧**。吸引力来自三件事——具体的受众任务、可兑现的承诺、低理解成本，而不是标题党或制造焦虑。

---

## 一、 10 类题材结构速查库

写稿前先定类型，再套结构；每段在心里标出作用（问题 / 答案 / 证据 / 例子 / 反例限制 / 行动），相邻两段之间必须能顺口说出“所以”或“但是”：

| 内容类型 | 推荐结构骨架 | 必备真实素材 | 常见误区 |
| :--- | :--- | :--- | :--- |
| 快速回答 | 结论 → 关键理由 → 一步行动 | 可直接验证的答案 | 故意绕弯子吊胃口 |
| 操作教程 | 成品先看 → 前提条件 → 步骤 → 成功标志 → 出错咋办 | 真实操作与失败分支 | 只念按钮名不说做成啥样 |
| 观点论证 | 判断 → 理由 → 例子 → 反例 → 适用边界 | 来源与反方视角 | 把情绪态度当证据 |
| 测评选择 | 使用任务 → 评判标准 → 同条件对比 → 代价 → 适合/不适合谁 | 测试条件与结果 | 只罗列参数不讲场景 |
| 经验故事 | 场景 → 目标 → 阻碍 → 行动 → 结果 → 反思 | 真实可核验经历 | 篇篇硬编逆袭套路 |
| 避坑排雷 | 问题 → 真实影响 → 解决法 → 验证方式 | 具体案例与可行步骤 | 夸大后果制造焦虑 |
| 结果展示 | 场景 → 承诺 → 实证过程 → 行动 | 前后对比与成本条件 | 只晒好结果隐去前提 |
| 门店/产品种草 | 具体需求 → 差异证据 → 适用人群与限制 → 行动 | 实物细节与真实反馈 | 铺垫过长没有实证 |
| 行业/热点解读 | 发生了什么（时间出处）→ 影响谁 → 依据 → 怎么应对 | 一手时间与出处 | 拿旧闻冒充新变化 |
| 知识科普 | 可观察现象 → 为什么 → 概念（先例子后术语）→ 怎么用 | 准确原理与生活例子 | 先抛一串抽象名词 |

## 二、 开头 3 选 1 机制与承诺审计

- **有可核验数据时优先“数据反常识”**（提问 → 否定直觉 → 抛一个直观数字 → 接核心原因）。
- 每次给出 3 个不同机制的开头（数据反常识 / 具体场景 / 误解纠偏），并强制标明**正文第几段兑现该承诺**；正文撑不起就收敛标题，绝不透支信任。
- **双文件解耦交付（`raw_intel_ingest.export_script_deliverables`）**：
  - `00_口播纯享稿.txt`：零 Markdown、零停顿符与画面提示，放进提词器直接顺口开念；
  - `00_拍摄执行方案.md`：包含 3 选 1 开头、带画面配合的逐字稿、超长易喘气句提示与待补核实清单。

## 三、 四轮分焦审稿清单（`raw_intel_ingest.lint_script` 自动预检）

1. **第 1 轮 · 事实与承诺**：有无编造经历/数字？有无“全网第一/100%/必火/99%的人不知道”等夸大词？标题、封面字与第一句是否指向同一个问题？
2. **第 2 轮 · 结构与删除测试**：做反向提纲，两段说同一件事就合并；删掉某段主线还成立就果断删；中段每 15–25s 要靠新例子/转折/反例维持推进，不靠“注意了、重点来了”硬撑。
3. **第 3 轮 · 口播可念性**：模拟大声念一遍，超过 16 字需要换两次气的拆成短句；第一句不用悬空的“这个/那个/它”；抽象名词改成具体动作；全稿字数按约 4–4.5 字/秒核对目标时长。
4. **第 4 轮 · 平台纯净度**：剔除跨平台残留话术（如发小红书却念“点左下角小黄车”、发抖音却说“一键三连”）。

## 四、 多平台差异化重写与复盘防误判矩阵

同一条片子跨平台发布时，用 `step9_title_cover.py` 生成的 `09_publish_copy_pack.md` 按场景重写入口，不要一键群发：
- **抖音 / 视频号**：标题 ≤28 字、正文 ≤100 字；抖音重“陌生人 1 眼认出具体问题”，视频号重“能被自然转发给同事/朋友的转述理由”。
- **小红书**：标题 ≤20 字、正文 3–4 小段，强调适用条件与“收藏备用”价值。
- **B 站**：标题 ≤40 字，信息 + 悬念完整兑现，简介给清晰脉络，配置顶评论引导讨论。

### 发布后复盘防归因谬误对照表
| 数据现象 | 优先核查项 | 可尝试的单变量改动 | ⚠️ 千万别直接下的武断结论 |
| :--- | :--- | :--- | :--- |
| 曝光偏低 | 题材需求度、发布窗口、主题清晰度 | 让标题和首帧对象更具体 | “一定是开头不够刺激” |
| 有曝光没点击 | 标题与封面是否说同一件事、小图字是否清晰 | 精简封面主大字并补强对比度 | “标题越夸张越好” |
| 开头流失大 | 前 2 句是否兑现了标题、有无多余寒暄铺垫 | 砍掉铺垫直接给现象或结果 | “所有视频都必须套同一句开头公式” |
| 中段掉人 | 对应秒数是否在原地重复、逻辑跳跃或难懂 | 补一个生活例子或删掉重复论证 | “加炫酷转场就能解决” |
| 某处回看峰值 | 是内容精彩、步骤太快，还是没听懂？ | 放大关键演示或放慢该句解释 | “有回看峰值就一定是爆点” |
| 播放高转化低 | 适用人群是否说清、证据与下一步行动是否顺畅 | 补充最常见顾虑的直接回答 | “一定要多喊几遍快关注快下单” |
