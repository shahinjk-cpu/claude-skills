## 一、 双轨判定、三有原则与账号门面

### 1. 先猜后确认双轨制
| 维度 | 门店轨（实体店/本地商家） | 博主轨（个人创作者/知识或泛娱乐） |
| --- | --- | --- |
| **定位模型** | 偏向 `To C`（到店/产品）或 `To B`（定制/方案） | 偏向 `曝光`（大众流量 → 广告/打赏/带货） |
| **成功标准** | **评论区咨询、私信留资、核销到店** | **开头留人、看完全片、净涨粉** |
| **核心打法** | 主打「晒细节 + 亮老板底线」建信任 + 局部同城热话题拉新 | 主打「热话题拉人 + 高密度干货」 + 强情绪/反常识开头 |

### 2. 三有原则与商业前置两问
- 动笔前先答两问：**① 客户要买什么？ ② 要赚谁的钱？**
- 成交链路：`看到 → 知道 → 动心 → 犹豫 → 成交`
- 每条内容至少命中「三有」之一：**有用处**（省钱/避坑/技巧）、**有兴趣**（新鲜/反差/看结局）、**有共鸣**（说中委屈/经历）
- 用户社会特征 6 维：`年龄` | `性别` | `地理位置` | `职业` | `收入消费力` | `家庭角色`

### 3. 账号主页四个位置（起号先改）
1. **头像**：门店字标 logo（多店/连锁）或 老板半身正脸工作照（单店靠人带店），二选一别混；
2. **名称**：`行业 + 品类 + 昵称`（例：王姐牛油老灶火锅）；
3. **背景图**：主页最上方 5:1 横条，只放门店实景或老板干活图，不放纯文字口号；
4. **简介四行**：① 开了几年/几家店背书 → ② 想做成的事 → ③ 招牌产品与价位 → ④ 电话或怎么搜店名。

## 二、 观众五阶段与三阶段发片配比（4 周日历算法）

| 内部阶段 | 大白话定位 | 常见拍法 |
| --- | --- | --- |
| **A1** | 拉新视频（让更多人刷到） | 热点借势、同城话题、强食欲/强视觉制作过程特写 |
| **A2** | 建信任视频（让人记住你这个人） | 老板出镜聊自己、创业经历故事、基础辨真假科普 |
| **A3** | 打消顾虑视频（让人想咨询下单） | 选购深度干货、回答人均/价格/常见疑问、老客见证、服务环境实拍 |
| **A4** | 照顾老客视频（让人放心复购） | 服务过程展示、出问题怎么售后兜底、感谢支持 |
| **A5** | 宠粉互动视频（激活回头客） | 新品抢先看、老客专属福利与投票共创 |

- **阶段一（刚起号冷启动）**：`50% 拉新` + `30% 建信任` + `20% 打消顾虑`（10 条里 5 + 3 + 2）
- **阶段二（稳态成长放量）**：`30% 拉新` + `40% 建信任` + `30% 打消顾虑`（10 条里 3 + 4 + 3）
- **阶段三（成熟门店复购）**：`20% 建信任` + `30% 打消顾虑` + `30% 照顾老客` + `20% 宠粉互动`（10 条里 2 + 3 + 3 + 2）

## 三、 六大变现脚本类型与五大找选题武器

### 1. 六大变现脚本类型
1. **晒过程**（露手艺/实力/质量）：创业日记、测评、挑战、事件体验、改造、现场解难题、成功案例
2. **讲故事**（破冰交朋友）：个人成就（双困境双转机）、人生遗憾、化解矛盾（可用五身份问卷「问事实·问感受·问转折」采素材）
3. **说观点**（找同类拉支持）：明确支持一方或反对行业乱象
4. **教知识**（立专业）：内幕揭秘、避坑、推荐建议、实用技巧、冷门知识
5. **说同城**（拉本地曝光）：本地城市/镇街反差话题 + 替城市站台
6. **进店理由**（给人来你家的直接理由）：围绕「人·货·场」展开

### 2. 八大吸引角度（内部称八大爆款元素）与词根
| 角度 | 原理 | 高频词根 |
| --- | --- | --- |
| **成本** | 赚到或浪费钱/时间/精力/脑力 | 便宜又有面子 / 血亏50块 / 怎么偷懒 / 捡漏 / 智商税 |
| **人群** | 点名特定人群或关注弱势小众 | 月薪2600打工人 / 刚失恋 / 负债50w / 高度近视 |
| **奇葩** | 扩展信息边界、外行不知道的内幕 | 世界最** / 骚操作 / 内幕 / 资深**不告诉你的 |
| **头牌** | 借标杆、名人、热点 | 雷军 / 胖东来 / 蜜雪 / 千万粉 / 细分第一 |
| **怀旧** | 共同记忆、遗憾、历史高光 | 小时候衣食住行 / 80后金曲 / 如果能重来 / 那年夏天 |
| **反差** | 身份/年龄/贫富/改造前后对立 | 老人做小孩的事 / 老板被员工说教 / 改造前后 |
| **最差** | 客观最低分或主观最踩坑 | 评分最低 / 拼多多9.9 / 最冤 / 最后悔 |
| **荷尔蒙** | 魅力强弱、情感/相亲吸引力（注：课件同时收录 p58 魅力强弱与 p121 原词表） | 好找对象的 / 显得很油的 / 夫妻感情 / 搭讪 |

### 3. 进店理由「人 · 货 · 场」14 条
- **人**：老板实在 / 老板专业 / 服务贴心 / 老客故事
- **货**：效果好（前后对比） / 质量好 / 性价比 / 有特色 / 选择多 / 有面子
- **场**：说走就走（近/好停） / 人气旺（排队断货） / 实力看得见（后厨设备） / 呆得住（环境氛围）

### 4. 另外三大挖题法
- **25 宫格拼词搜索**：中心 1 格行业 + 内圈 8 格行业词 + 外圈 16 格人群/场景 → 拼词丢抖音搜「最多点赞 + 一周内」；
- **客户五层问题**：表层想要什么 → 为什么想要 → 背后真正在意什么 → 最怕什么 → 什么才让他放心；
- **六大话题切口**：社会话题 / 身份话题 / 认知反转话题 / 行业内幕话题 / 立场争议话题 / 群体情绪话题（可叠两层），同步扒同行评论区咨询和自己私信。

## 四、 文案三段式、事件铁律与 17 种拍法

### 1. 动笔铁律：先定事件，再写文案（写前写后双自检）
- **三段呼吸**：开头 `0–3秒` 留人 → 中间 `3–45秒` 交付信息建信任 → 结尾 `末3秒` 促动作；
- **写前自检**：**一句话能不能说清发生了什么事？** 说不清，别写稿！
- **三步出稿**：① 找冲突点定具体事件 → ② 选中间结构 → ③ 填**数字 / 动作 / 原话对话**；
- **语言双法则**：**用看得见的画面代替抽象感受** + **把专业词换成老奶奶也听得懂的大白话**。

### 2. 开篇抓人工具箱
- **开篇细节**：**第一眼画面永远大于第一句话**；前 3 秒三句带劲的话配 2 次以上画面切换；开篇必须是一个具体事件；在店内拍、带运镜、说话有情绪。
- **八大切入点**：人群点名 / 戳中痛点 / 效果前置 / 强情绪（争议/共情/恐吓/痛苦） / 反常识好奇 / 资深身份或真实见证 / 颠覆常识 / 抛出疑问。
- **十大开篇写法**：`不字开头` | `先回应质疑(制造对手)` | `替观众说出心里话` | `付出代价才明白的缺口` | `反常识对立句` | `你信不信对赌` | `高密信息叠加(场景/时间/痛点/人物选4)` | `狠数字堆前面` | `全城就我家稀缺感` | `身份与动作强冲突`。
- **晒过程专属**：把最值钱/最意外的完整一幕直接放最开头；3 秒切一镜，不重复镜头，不留无意义的空镜头。

### 3. 中间六种讲法 + 四种收尾（推荐「一主一辅」）
- **六种中间骨架**：
  1. **露性格讲真话**（对应水桶/漏斗五段：性格[较真/倔强/温柔/直爽]、初心、原则、经历、价值观、态度）
  2. **先抛结果 → 讲原因 → 给方法**（开头抛的数字中间必须兑现）
  3. **现场追问八个问题**（不会写稿直接聊：`为什么呢 / 所以呢 / 还有呢 / 比如呢 / 真的假的 / 你会怎么做 / 然后呢 / 总结一下`）
  4. **拿真实案例说话**（谁 + 多久 + 什么结果 + 别人照做的 1、2、3 步）
  5. **预告后面还有干货**（观点 + 还有 2–3 个细节没说 + 把最值钱的放最前面讲）
  6. **先说外行误区 → 亮身份 → 拆内行真话**（反转后立刻拿事实证据）
- **四种结尾（建议一主一辅）**：`金句收尾` | `讲清感悟` | `抛具体问题让评论区聊起来` | `重申老板底线（我就是个XX的人+所以我XX+对得起XX）`。

### 4. 17 种口播拍法与拍摄分镜稳度标准
- **常用 5 种**：正对镜头（干货）/ 俯视视角（秘密感）/ 近距离悄悄话 / 边走路边拍 / 副驾侧拍；
- **生活真实类**：借头枕拍 / 车内关灯自拍 / 坐马路边 / 躺床上 / 边吃边拍 / 沙发上 / 躲被窝 / 边干活边拍；
- **借景与免背词**：借门缝拍 / 边写板书边拍 / 边开门边拍 / 内心 OS 配音。
- **拍摄 6 条与稳度规则（方案 1A）**：不要正面对着人硬拍；不用美颜、不炫技；**说话情绪大于一切**；推荐 iPhone 15+ 或 Pocket 3；**口播/第一视角晒过程允许轻微自然手持呼吸感**，**产品特写与单据/价格物证镜头必须手肘贴稳锁焦防糊**。

## 五、 面向用户的标准化大白话交付模板（严禁带黑话）

### 1. 4 周内容日历单行字段（给用户看的版本）
`| 周次/序号 | 这条视频干嘛用 | 怎么拍的类型 | 靠什么吸引人 | 一句话讲清什么事 | 开头抓人写法 | 拍法建议 | 选题标题 | 预期带来什么结果 |`

> 填表提醒：
> - 「这条视频干嘛用」填：`拉新让更多人认识` / `建信任记住老板` / `打消顾虑促咨询` / `照顾老客` / `宠粉互动`（严禁填 `A1`、`5A`）；
> - 「怎么拍的类型」填：`晒干活过程` / `讲真实故事` / `聊行业看法` / `教实用知识` / `聊本地同城` / `给进店理由`；
> - 「靠什么吸引人」填大白话，如：`算钱对比`、`前后反差`、`揭秘内幕`、`点名一类人`等。

### 2. 单条视频文案说明头（给用户看的版本）
```markdown
> **这条片子的设计思路（大白话版）**
> - **适用方向**：帮实体店同城获客 / 帮个人号涨粉引流
> - **这条片子干嘛用**：（例：让附近不知道你的路人先停下来认识你，占本阶段 10 条里的 5 条）
> - **一句话说清发生什么事**：（写稿前必过自检，必须是一件具体事，不能是空口号）
> - **客人心里真正怕什么 → 怎么让他放心**：怕「...」 → 靠「...」让他信你
> - **整条怎么串起来**：（例：先用大家爱聊的本地事把人拉住 → 再晒实打实的细节和老板底线 → 顺带提自家店）
> - **开头 3 秒怎么抓人**：画面先看「...」，第一句话用「...」（例：直接反着说/先丢最狠的数字/回应别人质疑）
> - **中间怎么讲、怎么收尾**：用「...」（例：先说结果再拆 3 步做法 / 亮出较真脾气），结尾用「...」让评论区聊起来
> - **建议怎么拍**：（从 17 种拍法里挑最省事的 1 种，如「边干活边拍」「副驾侧拍」「店里边走边聊」）
```
