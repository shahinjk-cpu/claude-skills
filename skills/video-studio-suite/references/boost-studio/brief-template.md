# Brief template

Save per reel as `projects/<name>/brief.md`. Merge the reusable lines into `brands/<brand>/MOTION.md`.

```
# Brief: <name>
Brand: <brand>   Networks: instagram, facebook   Post: <date/time or "later">
Goal / one action: <...>        Audience: <...>
Language: <ku/ar/en>  (Kurdish text = draft until the owner approves)
Length: <8/15/30 s>             Voice: <none | Kurdish voiceover; ElevenLabs credits approved: yes/no>
Hook (chosen): <line>           Proof / numbers allowed: <list from brand.json or "none">

## Locked choices
Style:     <A/B/C = description>
Color:     <...>
Layout:    <...>
Text:      <...>
Animation: <...>
Speed:     <...>
Sound:     <...>

## Cost (state before spending; ask again if the real cost passes the estimate by more than 30%)
Estimate: <credits / USD, or "free">      Approved by owner: yes/no      Actual: <fill after render>

## Decisions (one line each: what was chosen, one alternative, the reason)
- <e.g. voice: ElevenLabs "X" over silent, because the owner wanted a spoken hook>

## Material
<sketch / video / photos / logo paths>

## Approvals
[ ] questions answered   [ ] hook   [ ] style board picks   [ ] still   [ ] preview   [ ] final file   [ ] copy + time (for /post)
```

## MOTION.md (per brand, reusable)
```
# <Brand> motion rules
Palette: <...>        Type: <fonts, sizes>          Safe area: top 150, bottom 250
Latest board pick (what the owner chose on the style board last time; suggested as the starting look):
  style <...>, color <...>, layout <...>, text <...>, animation <...>, speed <...>, sound <...>
Preferred (approved in 2+ reels, or the owner said "always"):
  style <...>, color <...>, layout <...>, text <...>, animation <...>, speed <...>, sound <...>
Confirmed (counts of approved reels per option):
  animation: spring pop x3, slide x1 | sound: quiet music x2 | ...
Avoid (the owner rejected it or said stop): <...>
Log (newest first, every change dated and approved by the owner):
- <date> promoted <option> to Preferred after <n> approved reels
- <date> <reel>: <what performed, from real analytics, or what to drop>
```
