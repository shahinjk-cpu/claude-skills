# OpenSEO — Technical Search Optimization & Audit Engine

Executes automated technical SEO audits and programmatic content optimization to achieve top search engine rankings and AI answer engine (AEO) visibility.

## Audit Checklist
1. **Structured Data**: Inject JSON-LD Schema (`Article`, `Product`, `FAQPage`, `SoftwareApplication`).
2. **Core Web Vitals**: Target LCP < 2.5s, CLS < 0.1, INP < 200ms.
3. **Meta Architecture**: Canonical URLs, OpenGraph images, twitter summary cards, and hreflang tags.
4. **Robots & Sitemaps**: Dynamic XML sitemap generation with priority and lastmod stamps.
