# Archify — Architecture Modeling & System Diagramming

Scans source code repositories to automatically infer system topologies, service boundaries, database relationships, and C4 model architecture diagrams.

## Output Types
- **C4 Context & Container Diagrams**: High-level boundaries and protocol edges.
- **Component & ER Diagrams**: Database schemas and foreign-key relationships.
- **Sequence Diagrams**: Authentication flows and distributed transaction lifecycles.
