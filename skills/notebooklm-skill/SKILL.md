# NotebookLM — Source Grounding & Audio Overview Generator

Connects agents to Google NotebookLM methodologies: grounding all responses strictly in uploaded source material, generating study guides, executive briefs, and audio overview podcast scripts.

## Core Rules
1. **Strict Source Grounding**: Never speculate beyond provided source material; state exact citations and paragraph references.
2. **Audio Overview Scripting**: Generate natural, conversational two-host dialogues (Host 1: curious/inquisitive, Host 2: domain expert/insightful) breaking down complex documents.
3. **Cross-Document Synthesis**: Compare contradictory perspectives across multiple source files and highlight consensus vs divergences.
