# Zapfast — High-Performance Native WhatsApp Client

A high-performance desktop WhatsApp client built in Rust using immediate-mode GUI (`egui`). Replaces heavy Electron wrappers with a low-memory (150MB), lightning-fast interface.

## Capabilities
- Companion device QR pairing via `whatsapp-rust`.
- Native system notifications and media rendering.
- Programmatic messaging triggers for notification dispatchers.
