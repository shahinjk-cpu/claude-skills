# Daftar pilihan kata literer lengkap (dari pengguna, 2026-11-25)

Referensi utama saat mengaudit naskah. Format: sehari-hari → literer/lebih baik.

Catatan register: untuk novel yang memakai bahasa tengah (skill novel-bahasa-tengah), padanan yang ditandai (K)
terlalu kaku dan jangan dipakai di narasi: tatkala, sesungguhnya, hendak, menyantap, engkau, kelak, telah berulang.
Pakai padanan lain di baris yang sama.

## 1. Penghubung, waktu, transisi
- sama → dan, bersama, beserta
- pas → saat, ketika, tatkala (K)
- terus → lalu, kemudian, selanjutnya
- abis / habis itu → setelah itu, sesudahnya
- sebelum itu → sebelumnya
- sekarang → kini, saat ini
- tadi → beberapa saat lalu, sebelumnya
- nanti → kemudian, kelak (K)
- barusan → baru saja
- lagian → selain itu, lagi pula
- emang → memang, sesungguhnya (K)
- soalnya → karena, sebab
- makanya → oleh karena itu, maka dari itu
- tapi → tetapi, namun, akan tetapi
- kalo → jika, apabila, kalau
- walaupun → meskipun, sekalipun
- meskipun begitu → meskipun demikian
- sementara itu → sementara itu, di saat yang sama
- setelah itu → kemudian, tak lama kemudian
- tiba-tiba → tiba-tiba, mendadak
- langsung → segera, seketika
- cepet-cepet → tergesa-gesa, buru-buru
- pelan-pelan → perlahan, pelan-pelan
- diam-diam → diam-diam
- tiba-tiba aja → tiba-tiba saja, tanpa diduga

## 2. Kata kerja
- bilang → berkata, ucap, tutur
- ngomong → berbicara, berkata
- liat → memandang, menyaksikan, menatap, mengamati, melihat
- dateng → tiba, hadir, datang
- ketemu → bertemu, menjumpai
- ngerti → memahami, mengerti, menyadari
- mau → ingin, hendak (K), bermaksud
- bisa → mampu, dapat
- gak / enggak / nggak → tidak, tak
- udah → sudah, telah (K bila berulang)
- lagi (progresif) → sedang, tengah
- nyari → mencari · nemu → menemukan · kasih → memberikan, menyerahkan
- minta → meminta, memohon · tolong → membantu · tunggu/nungguin → menunggu
- lari → berlari, melarikan diri · jalan → berjalan, melangkah · berdiri → berdiri, bangkit
- tidur → tertidur, beristirahat · bangun → terbangun
- makan → makan, menyantap (K) · minum → meminum, meneguk
- nulis → menulis · denger → mendengar, menyimak · bau → mencium, tercium
- pegang → memegang, menggenggam · lepas / nyopot / copot → melepaskan, membuka
- masuk → memasuki · naik → menaiki
- ngejar → mengejar · ngikutin → mengikuti · ninggalin → meninggalkan
- ngerasa → merasakan, merasa · mikir → berpikir, merenung · inget → teringat, mengingat
- kaget → terkejut · seneng → senang, gembira · marah → marah, geram, murka
- cape / capek → lelah, kelelahan · teriak → berteriak, menjerit · bisik → berbisik
- pukul → memukul, menghantam · sobek → menyobek · rusak → rusak, porak-poranda
- ngumpet → bersembunyi · nyelinap → menyelinap · nyelonong → menerobos, masuk tanpa izin
- kabur → melarikan diri, meloloskan diri · ngebut → melaju kencang · ngendap → mengendap-endap

## 3. Sifat dan keterangan
- banget → sangat, sekali, amat · gitu → begitu, demikian · kayak → seperti, seolah, ibarat
- lumayan → cukup · keren → mengagumkan, hebat · jelek → buruk · bagus → baik, indah
- gede → besar, luas · kecil → kecil, mungil · cepet → cepat, segera · rame → ramai, hiruk-pikuk
- sepi → sepi, sunyi, hening · gelap → gelap, kelam · dingin → dingin, sejuk · panas → panas, gerah
- basah → basah, lembap · kotor → kotor, cemar · kasar → kasar, keras · lembut → lembut, halus
- tajam → tajam, menusuk · pucat → pucat, pucat pasi

## 4. Emosi dan tubuh
- deg-degan → berdegup kencang, berdebar hebat
- keringetan dingin → keringat dingin membasahi tubuh
- kaki lemas → kakinya lemas, lunglai · dada sesak → dadanya terasa sesak
- napas terengah-engah / naik turun → napasnya tersengal-sengal
- muka pucat pasi → wajahnya pucat pasi · mata melotot → matanya terbelalak
- hati berdebar → jantungnya berdegup kencang
- takut setengah mati → ketakutan mencekam · langsung kaget → terkejut bukan main
- gak karuan → tidak karuan, kacau balau · acak-acakan → berantakan
- matanya kosong → pandangannya kosong · badannya lemes banget → tubuhnya sangat lemas

## 5. Thriller dan mafia
- dibunuh → dilenyapkan, dihabisi · ketahuan → terpergok, tertangkap basah
- disuruh diam → diperintahkan bungkam, dipaksa melupakan
- ancaman → teror, bayang-bayang bahaya · kejaran → pemburuan
- ditagih → ditekan, diancam · orang berbahaya → sosok berbahaya, dalang di balik kejadian
- dunia mafia → dunia bawah tanah, jaringan mafia · parkiran gelap → parkir bawah tanah yang redup dan sunyi
(Catatan pedoman novel: jangan menambah detail cara membunuh.)

## 6. Kata ganti
- gue → aku, saya · lo → kamu, Anda (engkau = K) · dia → ia, dia (bergantian) · kita → kita, kami

## 7. Ungkapan
- aku lupa nyopotnya → aku lupa melepaskannya
- gak tau mau ngapain → tidak tahu harus berbuat apa
- lagi nungguin dia → sedang menunggunya
- pas lagi gelap-gelapnya → saat suasana sedang sangat gelap
- terus dia bilang → lalu ia berkata · abis itu dia pergi → setelah itu ia pergi
- kayak orang kesetanan → seolah kerasukan · langsung kabur → segera melarikan diri
- gak karuan pikirannya → pikirannya kacau

## Checklist narasi
A. Ketegangan: detail kecil (bunyi, cahaya, bau, getaran); kepanikan terasa; ritme pendek saat tegang; jeda; akhir adegan menyisakan pertanyaan.
B. Sudut pandang: konsisten; orang pertama dekat dan jujur; orang ketiga terbatas; tanpa kebocoran informasi; emosi lewat persepsi dan reaksi tubuh.
C. Bahasa: tanpa kata sehari-hari yang mengganggu di narasi; kalimat tidak berbelit; tanpa pengulangan; dialog natural; register narasi dan dialog berbeda; PUEBI.
D. Karakterisasi: cara bicara mencerminkan kepribadian; suara khas; reaksi manusiawi.
E. Keterbacaan: nyaman dibaca; transisi mulus; adegan mudah dibayangkan.
F. Thriller/mafia: bahasa mendukung rasa bahaya; detail sensorik kuat; kalimat aksi tajam; nuansa gelap terjaga.
