# AppFlowy — Local & Self-Hosted Knowledge Workspace

Integrates with AppFlowy, the open-source offline-first Notion alternative built with Flutter and Rust.

## Features
- **Grid, Board & Calendar Views**: Flexible database schemas with multi-select, dates, and relation properties.
- **End-to-End Encryption**: Host data locally or on private Cloud instances without telemetry.
- **Document Importer/Exporter**: Seamless Markdown and JSON document transfer.
